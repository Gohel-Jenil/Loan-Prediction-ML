How the System Works

  1. Enter applicant information.
  2. Submit the prediction form.
  3. The Flask backend preprocesses the data.
  4. The Gradient Boosting model generates a prediction.
  5. The prediction result is displayed on screen.

Important

This system predicts the likelihood of loan default based on patterns in the training dataset. The prediction is a statistical estimate and should not be treated as a final loan approval or rejection decision.
