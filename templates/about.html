About This Project

Loan Default Prediction using Gradient Boosting classification.

Project Objective

This project builds a Loan Default Prediction System using the Gradient Boosting Classifier. The objective is to predict whether a loan applicant is likely to default on loan repayment based on their financial profile, credit history, employment details, and loan specifications.

The target variable is Default (0 = No Default, 1 = Default).

Dataset

Records255,347 loan applications
Target VariableDefault (0 = No Default, 1 = Default)
Class Distribution~88.4% non-default, ~11.6% default (imbalanced)
Source FileLoan_default.csv
Features17 columns (9 numeric, 4 categorical, 3 binary, 1 ID)

Features Used

  • Age
  • Income
  • Loan Amount
  • Credit Score
  • Months Employed
  • Number of Credit Lines
  • Interest Rate
  • Loan Term
  • DTI Ratio
  • Education
  • Employment Type
  • Marital Status
  • Loan Purpose
  • Has Mortgage
  • Has Dependents
  • Has Co-Signer

Machine Learning Algorithm

Gradient Boosting Classifier — An ensemble method that builds sequential decision trees, where each tree corrects the errors of the previous one. The final prediction is a weighted combination of all trees.

Preprocessing

  1. Duplicate removal
  2. One-hot encoding for categorical variables (Education, Employment Type, Loan Purpose, Marital Status)
  3. Binary mapping for Yes/No features (HasMortgage, HasDependents, HasCoSigner)
  4. StandardScaler normalization for numeric features
  5. Train/Test split: 80/20 (random_state=42)

Evaluation Metrics

  • Accuracy — Overall correct predictions / total predictions
  • Precision — True positives / (True positives + False positives)
  • Recall — True positives / (True positives + False negatives)
  • F1-Score — Harmonic mean of Precision and Recall
  • ROC-AUC — Area Under the ROC Curve
