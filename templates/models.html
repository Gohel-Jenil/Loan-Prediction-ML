About Gradient Boosting

Gradient Boosting is an ensemble classification algorithm that builds a sequence of weak learners, where each new learner attempts to correct the errors made by previous ones. It combines many weak learners into a single strong learner by optimizing a loss function using gradient descent.

The model is trained on the Loan Default dataset (255,347 records) with features including applicant demographics, financial information, employment details, and loan specifications.
